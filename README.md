## About

**NXTGG** adalah layanan top up game online murah yang tersedia di Indonesia.  
Platform ini menyediakan berbagai kebutuhan top up untuk game mobile maupun desktop dengan proses cepat, harga terjangkau, dan metode pembayaran yang mudah digunakan.

NXTGG dibuat untuk membantu pemain game melakukan top up dengan lebih praktis, terutama saat ada event terbatas, bonus top up, gacha event, atau promo yang memiliki periode tertentu.

Fokus utama NXTGG adalah memberikan pengalaman top up yang:

- Cepat
- Mudah
- Aman
- Murah
- Tidak ribet

NXTGG menyediakan metode pembayaran yang mudah dan beragam untuk pengguna Indonesia:

- QRIS
- E-Wallet
- Virtual Bank
- Gerai
- Metode pembayaran lokal lainnya

### 🛡️ Transaction Security

NXTGG mengutamakan keamanan transaksi customer.

Jika terjadi kendala dari pihak sistem, seperti kesalahan API atau gangguan website, customer dapat dibantu sesuai kebijakan yang berlaku.

Catatan:

- Ganti rugi berlaku jika kesalahan berasal dari pihak NXTGG atau sistem
- Ganti rugi tidak berlaku jika kesalahan berasal dari customer, seperti salah memasukkan ID akun
